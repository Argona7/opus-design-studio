# Critique: be the art director, not the author

Inputs: every image from the last shoot (or the frames sheets), its warnings, DESIGN.md.

1. Look first. Describe what is actually on each screen, top to bottom, in plain words: what is big,
   what is small, which colours, where the eye goes first. No judgement yet. If you can't describe it,
   you haven't looked.
2. Count the defaults. Go through the numbered ban list in DESIGN.md screen by screen and list every default you
   can see (cream + serif + clay, black + one acid accent, caps eyebrows, middle dots, "→", one italic word,
   identical cards, fade-ins...). A default that DESIGN.md does not choose on purpose is a ban hit.
   Then check the rest of DESIGN.md line by line: every colour, font, size or gap that is not in the file.
   Name the screen and the element.
3. Score 1-10, with one line of evidence each:
   - hierarchy: one clear focal point per screen, an obvious reading order
   - type: pairing, contrast between sizes, line length, rhythm
   - colour: palette discipline, contrast, one accent
   - space: grid, alignment, consistent gaps, room to breathe
   - specificity: could this belong only to THIS business or person? Would a designer guess "AI made this"?
   - phone: readable, tappable, nothing cut off or overflowing (assets: readable at feed size)
   - craft: icons, borders, states, image quality, the details at 100 %
   - motion only: timing and easing, every frame readable, a new idea every few seconds, the ending
4. The 3-5 worst problems, worst first: where, what is wrong, the exact fix in values, not adjectives
   ("headline 56 → 72 px, tracking -0.02em", not "make it bolder").
5. Verdict: PASS only if every score is 8 or more, there are no ban hits and no unresolved warnings.
   Otherwise FAIL.

Harsh and specific beats kind and vague. If it already passes, say PASS and stop: don't invent problems.
